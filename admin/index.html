📥 Subir contenido nuevo

Sube un PDF o pega un link. Se integrará siguiendo las convenciones de la app y quedará como una Pull Request pendiente de tu revisión — nada se publica automáticamente.

Esto dispara un workflow de GitHub Actions que usa Claude para construir el contenido, lo verifica y audita contra la fuente, y abre una Pull Request en borrador. Sigue el progreso desde la pestaña Actions del repo o desde la app de GitHub en el móvil.
