# Extraction rules

- One value per field, with the **page** and the **verbatim quote** it comes from. The quote must be copied, not paraphrased.
- Numbers exactly as reported (keep units and the CI format). If you need to derive something (e.g. events from percentages), do not: mark the raw values and let the user decide.
- Not in the paper → `not_reported`. Do not fill from memory or from other papers of the same trial unless the user uploads them.
- Cannot read it (scanned page, table as image, separate supplement not uploaded) → `manual_extraction_required`, and tell the user where to look.
- Multiple reports of the same trial: extract from the primary report, note the others; ask the user which follow-up to use.
- Prefer intention-to-treat results; say which population each number refers to in the quote or value.
- After each study, show the user the values with their quotes and ask them to check at least the effect estimate and sample sizes against the PDF.
