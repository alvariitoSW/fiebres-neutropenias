# POCUS I · Cap. 2 Funciones del equipo / Knobología · extracto

Fuente: `docs/tamagnone-pocus-ecografia-critica-muestra-parte1.pdf` (=p1), pág. PDF 3-11 (impresa 35-43; impr. = PDF + 32). Leído entero. **El capítulo es un glosario de teclas; no contiene física ni una sola cifra de MHz, dB, PRF, atenuación, velocidad del sonido, resolución o frame rate.** Sombra, refuerzo, reverberación y espejo no se mencionan.

| Alcance | Para la práctica diaria basta saber unos pocos botones; los mandos cambian de marca y modelo | p1:3 |
| Probe/Exam | Elige sonda y tipo de estudio; en equipos sin pantalla táctil, con perillas | p1:3 |
| Freeze | Congela para medir o revisar; guarda en cine unos **10 s** hacia atrás; descongelado con la sonda parada para que no emita | p1:3-4 |
| Mode (B/2D) | Con B hay función **Dual**: 2 o hasta **4** imágenes (comparar momentos del ciclo) | p1:4 (fig. 2.1) |
| Modo M | Haz en pantalla marca la zona; **M anatómico**: el vértice se descuelga y se coloca donde se quiera, útil si la angulación impide medir perpendicular (si no, se sobreestima) | p1:4 (fig. 2.2) |
| Color | Caja (box) movible y redimensionable; **usar el menor tamaño de caja posible para no enlentecer la imagen** | p1:4 (fig. 2.3) |
| CW | Doppler continuo: haz para elegir la zona | p1:4 (fig. 2.4) |
| PW | Suma corrección del ángulo (perilla Angle o botones de **5, 10 o 15°**), volumen de muestra (Sample Volume), caja trapezoidal con steer; el flujo medido es el de la muestra (gota) | p1:4-5 (fig. 2.5) |
| PA/PWA/CPA | Power Doppler: flujos de muy baja velocidad; distingue oclusión de obstrucción severa | p1:5 (fig. 2.6) |
| TDI | Doppler tisular = PW ajustado; si no existe: bajar volumen de muestra, filtros de pared altos, escala **+20 a −20**, ajustar ganancia | p1:5-6 (fig. 2.7) |
| THI | Segunda armónica: mejora resolución y disminuye artefactos del 2D | p1:6 (fig. 2.8) |
| Meas/Calc, Cal | Paquete de cálculos según sonda y modo; caliper libre; trazado a mano alzada para áreas y volúmenes | p1:6-7 (figs. 2.9, 2.10) |
| Auto | Optimización automática de imagen | p1:6 |
| Update | Actualiza la pantalla al mover haz o volumen de muestra; repetir la tecla del modo también actualiza | p1:7 |
| Duplex/Triplex | 2 o 3 procesos en tiempo real (B + espectro; + color); pueden enlentecer el sistema | p1:7 |
| ECG | Obligatorio en eco cardíaca para medir fin de sístole/diástole; requiere cable paciente | p1:7-8 (fig. 2.11) |
| Zoom | Amplía zona **sin modificar la emisión**; varios niveles | p1:8 (fig. 2.13) |
| Depth | Al aumentar profundidad **baja la frecuencia de repetición de pulso** y puede perderse resolución | p1:8-9 (fig. 2.14) |
| Foco | Eleva la resolución a una distancia concreta; se coloca a la altura de lo que interesa | p1:9 |
| Gain | Más ganancia = más ecos; muy baja pierde señal verdadera, muy alta produce mota o saturación; en color: baja simula falta de flujo, alta exagera insuficiencia hasta saturar; 2D y Doppler separables | p1:9 (fig. 2.15 A-F) |
| Filtros de pared | Columna de perillas (ecualizador) por frecuencias | p1:9-10 |
| Trackball | Equivale al ratón; cursores y anotaciones | p1:10 |
| Línea de base | Sube/baja el cero del espectro; ordena la pantalla y mejora medidas y **aliasing** | p1:10-11 (fig. 2.16) |
| Invertir | Color azul↔rojo; espectro por encima↔por debajo; evita falsos artefactos como aliasing | p1:11 (fig. 2.17) |
| Escala | Debe ajustarse al territorio vascular; evita aliasing | p1:11 (fig. 2.18 A alta, B baja) |
| Velocidad de barrido | Cambia la velocidad de desplazamiento del espectro (también en ECG) | p1:11 (fig. 2.19) |

## Cifras de sondas del cap. 3 de POCUS II (p1:28, impr. 36; no es cap. 2)
Lineal **6-13 MHz** (arterial, venoso, musculoesquelético, nervio); convexa **3-8 MHz** (abdominal, ginecológico); cardíaca **1-5 MHz**. Profundidad 13 vs 19 (fig. 25, p1:37). Modo M: introducido a fines de los 60, «resolución alta de 1500» (sic, sin unidad; p1:29). Auto-freeze ~5 min; cine 4-10 s (p1:29). Foco: «incluso más de 2 focos» (p1:37). Filtros de pared y ganancia: p1:37-38.
